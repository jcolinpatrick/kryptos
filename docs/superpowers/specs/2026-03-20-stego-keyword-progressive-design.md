## Part 1: Stego Layer — Resolve 7 Varying Null Positions

8 cipher-based rules generate the (pos%7,pos%5) N/R table perfectly. Each rule = a 5-letter word + cipher variant + alphabet that, applied to KRYPTOS[pos%7] and WORD[pos%5], produces a value in a specific "null set." Each word predicts specific null/real assignments for the 7 varying positions.

**Method:**
- For each of the 8 table-generating rules, compute the predicted null/real status for positions in {38-45, 55-56, 87-88, 93-96}
- Filter: predicted nulls must have palette letters {B,G,I,K,O,W,Z} at those CT positions (or not — varying nulls are NOT palette-constrained per MEMORY)
- Filter: predicted mask must not remove any crib position (21-33, 63-73)
- Report which rules produce valid complete masks

## Part 2: Keyword × Progressive Function Sweep

**Hypothesis:** The keyword generates a non-periodic key via a progressive function, not simple repetition.

**Method:**
For each candidate keyword K of length p (3-12 letters):
  For each progressive function f from a catalog of ~30 functions:
    For each position i in {0..96} (CT97) or {0..72} (CT73):
      Compute key[i] = f(K, i, p) mod 26
    Check all 24 crib positions: does (CT[pos] + key[pos]) mod 26 match the known Beaufort keystream?
    If ALL 24 match → BREAKTHROUGH candidate

**Progressive function catalog:**
```
# Group A: Position-additive
f1(K,i,p) = K[i%p]                          # periodic (control — known impossible)
f2(K,i,p) = K[i%p] + i                      # linear progressive
f3(K,i,p) = K[i%p] + floor(i/p)             # step per keyword cycle
f4(K,i,p) = K[i%p] + i*K[(i+1)%p]           # keyword-modulated linear
f5(K,i,p) = K[i%p] + sum(K[0:i%p])          # cumulative keyword sum

# Group B: Keyword interaction
f6(K,i,p) = K[i%p] + K[(i+1)%p]             # adjacent pair sum
f7(K,i,p) = K[i%p] + K[(i-1)%p]             # previous pair sum
f8(K,i,p) = K[i%p] * K[(i+1)%p]             # adjacent pair product
f9(K,i,p) = K[i%p] XOR K[(i+1)%p]           # adjacent XOR (treat as mod 26)
f10(K,i,p) = K[i%p] + K[floor(i/p)%p]       # cycle-indexed addition

# Group C: Fibonacci/Gromark-like
f11(K,i,p) = K[i%p] + fib(i) where fib from keyword seed
f12(K,i,p) = running sum: key[i] = (key[i-1] + K[i%p]) mod 26

# Group D: Position-multiplicative
f13(K,i,p) = K[i%p] * (i+1)                 # multiplicative
f14(K,i,p) = K[i%p] * (floor(i/p)+1)        # cycle-multiplicative
f15(K,i,p) = K[i%p] + (i mod p) * (i mod p) # quadratic in residue

# Group E: Polybius-mediated
f16(K,i,p) = KA_row(K[i%p]) * 5 + KA_col(K[(i+1)%p])  # row/col interleave
f17(K,i,p) = K[i%p] + KA_row(K[i%p]) * (i%5)           # row-scaled position
f18(K,i,p) = K[i%p] + (i%7) * (i%5)         # KRYPTOS×SEVEN position modifier

# Group F: Chart-procedure inspired
f19(K,i,p) = K[effective_pos%p] where effective_pos skips null positions
f20(K,i,p) = K[i%p] reversed every other cycle (boustrophedon keyword)
```

Plus 10 more generated by combining modifiers (mod 5, mod 7, reversed keyword, etc.)
