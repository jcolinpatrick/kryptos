Never use a style="" attribute here: nginx serves the site under `style-src 'self'` with no 'unsafe-inline', so inline styles are dropped silently and the element renders unstyled. #} {# position_strip: the 97 carved characters as a scale drawing. Laid out as CSS Grid in fixed-width blocks rather than a wrapping flex row, because a ruler can only stay aligned to its letters if both sit in the same grid columns. Each block is three grid rows (ruler / ciphertext / plaintext) so alignment holds by construction at any width. ct the ciphertext string cribs [{start, text}] plaintext known to sit at that 0-indexed offset marks [{start, end, label, kind}] extra spans to tint (kind: anomaly|segment) per_row characters per block; 24 keeps a block readable on a phone #} {% macro position_strip(ct, cribs=[], marks=[], target=33, show_ruler=true, show_plaintext=true, caption='', label='') %} {% set n = ct|length %} {#- 97 is prime, so a fixed per-row count strands a remainder (24 gave four full rows and a single orphaned letter). Pick the row COUNT first, then divide as evenly as possible: 3 rows of 33/33/31 rather than 24/24/24/24/1. -#} {% set rows_n = (n / target)|round(0, 'ceil')|int %} {% set per_row = (n / rows_n)|round(0, 'ceil')|int %} {% set crib_at = {} %} {% for c in cribs %} {% for i in range(c.text|length) %} {% set _ = crib_at.update({c.start + i: c.text[i]}) %} {% endfor %} {% endfor %} {% set mark_at = {} %} {% for m in marks %} {% for i in range(m.start, m.end + 1) %} {% set _ = mark_at.update({i: m.kind|default('anomaly')}) %} {% endfor %} {% endfor %} {% endmacro %} {# segment_rule: the dimension callout beneath a strip.
