# Constraint Propagation Engine

You are reasoning backward from confirmed constraints to determine what
cipher mechanisms remain consistent with ALL of them simultaneously.
This is the inverse of the normal attack workflow (which tests mechanisms
forward). A mechanism that violates ANY single constraint is eliminated
without needing to run a single experiment.

## Why This Matters

880+ experiments have tested mechanisms forward. ZERO breakthroughs.
Bean says K4 is "like Chaocipher — not reasonably guessable." But we
have dense constraints from cribs, Bean's analysis, stego analysis,
and structural properties. A mechanism that satisfies ALL constraints
simultaneously is extremely rare — possibly unique. Finding it by
elimination is more tractable than finding it by search.

## The Constraint Set

summary for quick reasoning:

### Hard Constraints (violation = immediate elimination)

**C1 — Ciphertext properties:**
- CT = 97 chars, all 26 letters present, IC = 0.0361 (below random)
- 97 is prime (no rectangular grid fits perfectly)

**C2 — Two systems confirmed:**
- Stego layer (null mask) + cipher layer (substitution)
- Scheidt: "bit of stego," "masking technique may not be known"
- Sanborn: "pull up one layer, come to the next"

**C3 — Crib consistency:**

- Self-encrypting: CT[32]=PT[32]=S, CT[73]=PT[73]=K

  exact positions. No exceptions.

**C4 — Bean equality:**
- k[27] = k[65] (keystream values must be equal)
- Under Vigenère: both = 24 (Y)
- Under Beaufort: both = 6 (G)

**C5 — Bean inequalities (242 pairs):**
- Variant-independent: hold under Vig, Beau, AND Var-Beau
- ANY periodic key with period p where p divides gcd(27-pos, 65-pos)
  for any violating pair is eliminated
- ALL periods 1-26 are eliminated for periodic substitution on raw CT97

**C6 — Null palette:**
- {B,G,I,K,O,W,Z} at specific positions (p=2.4e-5)
- Generated by KRYPTOS×SEVEN Polybius on 5-wide KA grid
- 17 consensus null positions identified via (pos%7,pos%5) rule (35/35)
- 7 additional null positions unknown

**C7 — Keystream properties (at crib positions):**
- Vigenère keystream: non-periodic, IC = 0.029 (below random)
- AP {G,K,O} at 12/24 crib positions (p~4e-6) — but AP bias doesn't
  improve SA decryption quality
- No known key-generation function produces this keystream

**C8 — K5 position-dependence [HYPOTHESIS]:**
- K5 shares coded words at same positions → cipher is likely
  position-dependent, NOT state-dependent
- IF TRUE: eliminates Chaocipher, Enigma, rotor machines
- This is a hypothesis, not proven fact

**C9 — Structural properties:**
- K3 code chart: 14×24 grid (QUADRUPLE-24)
- ?+K4 = 98 = 14×7 (same width as K3 chart)
- 24 + 7 = 31 = panel width

- ENDYAHR at starting corner of K3 chart

**C10 — Sanborn's capabilities:**
- "Zero mathematical ability"
- "Embarrassingly simple once seen"

- Used encoding charts (grid worksheets) for K1-K3

### Soft Constraints (violation = strong evidence against, not proof)

## How To Use This Skill

### When evaluating a proposed mechanism:

Walk through EVERY hard constraint C1-C10 and ask:

1. **Is it consistent?** Does the mechanism produce the correct CT↔PT
   pairs at all 24 crib positions?
2. **Does it satisfy Bean?** k[27]=k[65] AND all 242 inequalities?
3. **Is it two-system?** Does it have a stego + cipher decomposition?
4. **Can Sanborn do it?** No computers, no advanced math. Encoding
   charts, grids, physical tools.
5. **Does it produce IC ≈ 0.036?** Not too high (not periodic), not
   too low.
6. **Is it position-dependent?** (Conditional on C8/K5 hypothesis)

Report a clear verdict for each constraint: PASS / FAIL / UNKNOWN.
If ANY hard constraint FAILs, the mechanism is ELIMINATED.
If all PASS, it's a SURVIVOR — worth testing computationally.

### When asking "what's still possible":

Start from the broadest cipher taxonomy and prune:

```
ALL CIPHER MECHANISMS
├── Monoalphabetic → ELIMINATED (C5: period-1 fails Bean)
├── Periodic polyalphabetic → ELIMINATED (C5: ALL periods 1-26 fail)
├── Autokey (PT or CT) → ELIMINATED (structural proof, crib feedback)
├── Running key → OPEN (non-periodic, high-entropy, consistent with C7)
│   ├── From known texts → 38 sources tested, ZERO (but source space huge)
│   └── From unknown text → untestable without the text
├── Position-dependent non-periodic → OPEN (consistent with C7, C8)
│   ├── Key = f(position) → 2,483 functions tested, ZERO
│   ├── Key from encoding chart lookup → OPEN (untestable without chart)
│   └── Key from physical process → OPEN (untestable computationally)
├── Transposition + substitution → partially tested
│   ├── Known transpositions + periodic sub → ELIMINATED
│   ├── Known transpositions + running key → ELIMINATED (TKAS)
│   └── Bespoke transposition + bespoke sub → OPEN (huge space)
├── State-dependent (Chaocipher, Enigma) → ELIMINATED IF C8 holds
├── Fractionation (Bifid, ADFGVX) → ELIMINATED (26 letters, 5×5 needs 25)
└── Novel/bespoke → OPEN
    └── Must satisfy C10 (Sanborn can do it with charts)
```

### When narrowing the search:

Ask these discriminating questions:

1. **Does the mechanism require a computer?** If yes → inconsistent
   with C10 (Sanborn: "zero mathematical ability")
2. **Does the mechanism use a repeating key?** If yes → eliminated
   by C5 (Bean inequalities kill all periods 1-26)
3. **Does the mechanism use preceding PT/CT as key?** If yes →
   eliminated (autokey proof, crib feedback contradictions)
4. **Does the key come from a text?** If yes → running key model.
   Source must be identified. 38 tested, all noise.
5. **Does the key come from the encoding chart?** If yes → OPEN.
   This is the most promising survivor class. The chart is a physical
   artifact that provides position-dependent key values.
6. **Is the mechanism self-inverting?** K3's double rotation is
   self-inverting. If K3/K4 share the same transformation type,
   self-inversion may be a design constraint.
